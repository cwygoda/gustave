# Plannotator

Use `plan_annotate` to write or update plan sections in a markdown file, usually `PLAN.md`.

Workflow:
1. Before edits, create a plan section with unchecked steps.
2. During execution, replace the section with updated checkboxes as steps complete.
3. Include validation commands and final status.
4. Use `/planfile path/to/file.md` if a task needs a non-default plan file.

Prefer plan files for substantial work. Keep plans concise and reviewable.
