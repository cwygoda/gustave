# Memory

Use Gustave memory only for stable, useful information.

Tools:
- `memory_search` — look up prior facts/preferences.
- `memory_save` — store a durable memory.
- `memory_delete` — remove obsolete or sensitive memory.

Guidelines:
1. Search memory at the start of tasks likely affected by user preferences or project conventions.
2. Save memory after explicit user preference, recurring environment setup, project decision, or important constraint.
3. Do not store secrets, API keys, credentials, or sensitive personal data.
4. Use concise keys and tags.
